Your AI, on your machine, on your terms.

Qwen Studio is a desktop app that connects a local LLM (GGUF format, llama.cpp engine) to an interface built for work: writing, coding, analyzing, and keeping its own memory, with no dependence on an external server.

Everything it ships with

Nine pieces living in the same window.

🖥️

100% local

The model runs on your own machine via llama.cpp; nothing you write leaves to an outside server.

🪄

Live Preview

The code it generates renders instantly in a separate panel, with its own console to see errors.

🧪

Automatic sandbox

Before handing you the result, it tests the generated code and can fix it on its own if something fails.

🛠️

Tool steps

Every action the agent takes (read, write, run) is visible as a step you can open.

🔌

MCP connectors

Add local MCP servers to extend what the model can do for you.

🎙️

Voice

Text-to-speech narration and speech recognition to talk to the app directly.

🧩

Nexus

Publish your creations to a shared hub under an anonymous pseudonym — no account needed.
👁️

Vision and attachments

Drag in images or files and the model analyzes them as part of the conversation.

🧠

Persistent memory

Saves durable facts between chats — editable and erasable by hand whenever you want.
